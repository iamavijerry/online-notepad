# Free Online Notepad

A clean, fast, and distraction-free browser-based text editor.
No login, no server, no data collection.

Live Demo: https://github.com/iamavijerry/online-notepad

---

Features:

* Rich text editor (bold, italic, underline, font family & size)
* Auto save using browser localStorage
* Find & replace with match counter
* Open .txt / .md / .html files
* Save and Save As options
* 80+ special characters (symbols, Greek letters, arrows, fractions)
* Insert date & time (multiple formats)
* Zoom in/out with proper text wrapping
* Dark mode (saved preference)
* Fullscreen mode
* Word, character, and line counter
* Clean print support
* Keyboard shortcuts (Ctrl+S, Ctrl+H, F11, etc.)
* AdSense-ready structure

---

Tech Stack:

* HTML5
* CSS3
* Vanilla JavaScript
* localStorage
* Font Awesome
* Google Fonts (Lora + JetBrains Mono)

---

How to run:

git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name

Then open: notepad.html in your browser

No installation needed. No server required.

---

Folder structure:

/

* notepad.html (main file)
* style.css (styles)
* script.js (logic)
* README.md

---

Keyboard shortcuts:

* New: Ctrl + N
* Open: Ctrl + O
* Save: Ctrl + S
* Save As: Ctrl + Shift + S
* Find & Replace: Ctrl + H
* Print: Ctrl + P
* Zoom: Ctrl + = / Ctrl + -
* Reset Zoom: Ctrl + 0
* Fullscreen: F11
